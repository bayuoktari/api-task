# Donation Backend

NestJS backend service for the donation platform.

## Local development

```bash
npm install
```

```bash
npm run start:dev
```

The API will be available at `http://localhost:3000`.

## Health check

```bash
curl http://localhost:3000/health
```

## Linting & formatting

```bash
npm run lint
npm run format
```

## Testing

```bash
npm test
```
